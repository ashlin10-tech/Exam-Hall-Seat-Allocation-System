# Exam Hall Seat Allocation System

## About the Project
The Exam Hall Seat Allocation System is a web-based application developed to automate the process of allocating students to examination halls and seats.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Features
- Student Management
- Department Management
- Exam Management
- Room Management
- Automatic Seat Allocation
- Invigilator Management
- Seating Layout
- Admin Dashboard
- Database Management

## Database
The project uses MySQL as the database.

Database file:
`exam_seat_allocation_db.sql`

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project folder into:
   `C:\xampp\htdocs\`
4. Open phpMyAdmin.
5. Create a database named:
   `exam_seat_allocation_db`
6. Import `exam_seat_allocation_db.sql`.
7. Open the project in your browser:
   `http://localhost/your-project-folder/`
